⚡ 最快啟動方式（三步搞定）

═══════════════════════════════════════════════════════════════════

第 1 步：打開終端機
────────────────────────────────────────
  Windows:  按 Win+R，輸入 cmd，按 Enter
  Mac:      按 Command+Space，輸入 Terminal
  Linux:    按 Ctrl+Alt+T


第 2 步：進入目錄並啟動
────────────────────────────────────────
  複製並執行以下命令：

  cd /home/user/test

  【Linux/Mac 用戶】
  ./start.sh

  【Windows 用戶】
  start.bat

  【或手動啟動】
  python3 -m http.server 9000


第 3 步：打開瀏覽器
────────────────────────────────────────
  在瀏覽器地址欄輸入：

  http://localhost:9000/test.html   ← 先測試這個
  http://localhost:9000             ← 然後打開主頁

❌ 遇到問題？

═══════════════════════════════════════════════════════════════════

1. 先打開 test.html 測試 API 連接
2. 按 F12 打開控制台查看錯誤
3. 確保使用本地服務器（不要直接打開 HTML 文件）
4. 查看 START_HERE.md 獲取詳細故障排除
